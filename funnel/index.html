Internal architecture / v1Behavior, not demographics

Attention
Pipeline.

One investigation becomes a multi-surface acquisition, conversion and retention system. The reader gives us almost nothing up front; the system learns only from consented first-party interaction with NYF.

The full loop.

Research → canonical record → East Corner + YouTube → Shorts/social → discovery → Evidence File → email → newsletter → return → editorial intelligence → next investigation.

The newsletter owns the relationship. The canonical record owns the reporting. Distribution surfaces create discovery. East Corner and YouTube create depth. The Evidence File converts intent into an email relationship.

01 / Source

Investigation

One thesis, one evidence base, one canonical content ID.

02 / Product

East Corner + YouTube

Written reconstruction and long-form audiovisual argument from the same reporting.

03 / Acquisition

Atomic distribution

Shorts, clips, visual claims and social fragments each carry an asset ID back to the investigation.

04 / Conversion

Evidence File

The source trail, timeline, numbers, classifications and unresolved questions. Email only.

05 / Relationship

The Dispatch

Delivery and return channel. No demographic questionnaire.

06 / Intelligence

Behavioral cohorts

Acquired-by-story, evidence seekers, long-form readers, newsletter returners and cross-surface readers.

What we capture.

Acquisition content and asset, source and medium, landing path, coarse reading depth, meaningful engagement, Evidence File request, newsletter conversion, return visits and movement between NYF surfaces.

We do not collect or infer demographic identity, precise location, sensitive traits, device fingerprints, third-party browsing history or purchased audience profiles.

Acquisition

What brought serious readers?

Investigation, derivative asset, source, medium and landing path.

Conversion

What created intent?

Evidence CTA views, Evidence File requests and newsletter signups.

Retention

What brought them back?

Newsletter clicks, return visits and second-investigation movement.

Compounding

What deserves more reporting?

Stories that create both acquisition and retention rather than empty pageviews.

The acceptance test.

A reader encounters one NYF Short, reaches the full investigation, requests its Evidence File with only an email address, receives it, returns through the Dispatch to a second investigation, and is counted as a returning evidence-seeking reader without NYF asking who they are demographically.
